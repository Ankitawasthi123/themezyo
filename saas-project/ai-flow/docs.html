Getting Started

Welcome to AIFlow API. Follow the steps below to start integrating AI into your application.

1. Create an Account

Sign up and get your API key from the dashboard.

2. Make Your First Request

POST /v1/chat/completions
{
  "model": "gpt-4o",
  "messages": [{"role": "user", "content": "Hello"}]
}

3. Get Response

You will receive the AI response in JSON format.
